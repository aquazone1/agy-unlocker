# Промпт для генерации изображений и видео через agy-google

Скопируйте текст ниже в сессию агента на сервере с установленным agy-unlocker
(порядок установки — в `INSTALL_PROMPT_RU.md`).

---

На этом сервере установлен agy-unlocker: обёртка `~/.local/bin/agy-google`,
проверенная схема из `INSTALL_PROMPT_RU.md`. Мне нужно генерировать изображения
и, если возможно, видео через мой личный аккаунт Google. Выполняй команды сам;
помощь запрашивай только при отсутствии OAuth-входа или неработающем прокси.

Подтверждённые факты от 5 ноября 2026 года (CLI 1.4.12, прокси Xray,
выход Германия 2.1):

- Генерация изображений через CLI **работает**: модель сохраняет настоящий
  файл PNG (проверено: 1024x1024, ~880 КБ). Проверены `gemini-3.8-flash-low`
  и `gemini-3.8-flash-high`; картинка сгенерирована с `flash-low` за ~35 с.
- Генерация видео через CLI **не работает**: обе модели честно отвечают, что
  генерация видео в этом интерфейсе недоступна, файл не создают. Видео (Veo)
  доступно в браузерном интерфейсе Antigravity и через платный Gemini API —
  это отдельные задачи, не зависящие от этой схемы.

Порядок работы:

1. Убедись, что прокси жив и OAuth-вход выполнен — выполни базовый тест из
   `INSTALL_PROMPT_RU.md` (ожидается `GOOGLE_OK`, код 0). Не продолжай без него.

2. Создай рабочий каталог для медиа, например `~/media`, и запусти генерацию
   изображения. Обязательные флаги:

   `--add-dir <каталог>` — каталог, куда модель сохранит файл; без него
   сохранение вне текущего рабочего каталога отклонено.

   `--dangerously-skip-permissions` — без интерактивного терминала запросы
   на одобрение инструментов никто не подтвердит, и сохранение файла
   заблокируется.

   ```bash
   mkdir -p ~/media
   timeout --foreground -k 5s 280s ~/.local/bin/agy-google \
     --model gemini-3.8-flash-low \
     --disable-slash-commands --dangerously-skip-permissions \
     --add-dir ~/media --print-timeout 240s \
     -p 'Сгенерируй изображение <описание> и сохрани его как <имя>.png в ~/media. Ответь одной строкой с путём к файлу.'
   echo "Код завершения: $?"
   ```

3. Проверь результат как файл, а не как текст ответа:

   ```bash
   ls -la ~/media
   file ~/media/<имя>.png
   ```

   Успех — существует валидный PNG/JPEG ненулевого размера. Текстовый путь
   в ответе модели сам по себе файл не доказывает.

4. Промпт формулируй явно: «сгенерируй изображение» + точное имя файла +
   формат. Модель умеет и редактировать: дай ей путь к исходнику через
   `--add-dir` и описание правки.

5. Видео через этот CLI не запрашивай: схема проверена и не работает
   (см. подтверждённые факты выше). Для Veo используй браузерный Antigravity
   или Gemini API отдельно.

6. Заверши отчётом: путь к файлу, размер, формат, код завершения, модель,
   время генерации. Секреты, токены и подписку не публикуй.
