# Промпт для генерации изображений и видео через agy-google

Скопируйте текст ниже в сессию агента на сервере с установленным agy-unlocker
(порядок установки — в `INSTALL_PROMPT_RU.md`).

---

На этом сервере установлен agy-unlocker: обёртка `~/.local/bin/agy-google`,
проверенная схема из `INSTALL_PROMPT_RU.md`. Мне нужно генерировать изображения
и видео через мой личный аккаунт Google. Выполняй команды сам; помощь
запрашивай только при отсутствии OAuth-входа, неработающем прокси или
необходимости входа в Gemini в браузере.

Подтверждённые факты от 5 ноября 2026 года (CLI 1.4.12, прокси Xray,
выход Германия 2.1):

- Изображения через CLI **работают**: `agy-google -p` с флагами ниже сохраняет
  настоящий PNG (проверено: 1024x1024, ~880 КБ, `gemini-3.8-flash-low`, ~35 с).
- Видео через CLI `print`-режим **не работает**: модели честно отвечают, что
  генерация видео в этом интерфейсе недоступна.
- Видео **работает** через браузерный интерфейс Gemini (gemini.google.com,
  Veo): `agy-google` с инструментом `/browser` управляет открытым Chrome
  (CDP), вводит промпт, выбирает «Create video» и Portrait (9:16) и жмёт
  Download — оригинал сохраняет сам Chrome. Схема работает в бою для
  ежедневных сторис; эталонная реализация: `story_google.py` в проекте
  `tg_assistant` (подготовка вкладки через CDP, `Browser.setDownloadBehavior`,
  проверка скачанного файла через PIL/ffprobe, запрет повторной отправки).

Порядок работы:

1. Убедись, что прокси жив и OAuth-вход выполнен — базовый тест из
   `INSTALL_PROMPT_RU.md` (ожидается `GOOGLE_OK`, код 0). Не продолжай без него.

2. Изображение через CLI. Обязательные флаги:

   `--add-dir <каталог>` — каталог для файла; без него сохранение вне
   рабочего каталога отклонено. `--dangerously-skip-permissions` — без
   интерактивного терминала одобрить инструменты некому.

   ```bash
   mkdir -p ~/media
   timeout --foreground -k 5s 280s ~/.local/bin/agy-google \
     --model gemini-3.8-flash-low \
     --disable-slash-commands --dangerously-skip-permissions \
     --add-dir ~/media --print-timeout 240s \
     -p 'Сгенерируй изображение <описание> и сохрани его как <имя>.png в ~/media. Ответь одной строкой с путём к файлу.'
   echo "Код завершения: $?"
   ```

3. Проверь результат как файл, а не как текст ответа:

   ```bash
   ls -la ~/media && file ~/media/<имя>.png
   ```

   Успех — валидный PNG/JPEG ненулевого размера. Текстовый путь в ответе
   модели сам по себе файл не доказывает.

4. Видео и сложные композиции — через браузерный Gemini, как в `story_google.py`
   (`tg_assistant`): отдельный Chrome-профиль с действующим входом в аккаунт,
   прокси в этом Chrome обязателен (трафик Google идёт с IP выхода),
   управление по CDP, исходник забирает только Chrome-загрузка, файл
   валидируется ffprobe (для сторис — вертикаль 9:16). Одна отправка запроса,
   без регенераций; при ошибке квоты/авторизации — остановиться и отчитаться,
   а не слать повторно. Копировать схему целиком из `story_google.py`, а не
   изобретать параллельную: там уже выверены ожидания UI, таймауты и защита
   от двойной отправки.

5. Заверши отчётом: путь к файлу, размер, формат, код завершения, модель,
   время генерации. Секреты, токены, подписку и cookies Chrome не публикуй.
