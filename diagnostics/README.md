# Сохранённая диагностика

Эти скрипты сохранены как наработки, а не как подтверждённый способ проверки подписки.

- `check_google.py` читает OAuth-токен из стандартного хранилища CLI и делает
  HTTP/1.1-запрос `loadCodeAssist` через локальный прокси. Токен не выводит.
  Метаданные запроса упрощены, клиентские заголовки полностью не воспроизводятся:
  полученный `UNSUPPORTED_CLIENT` не доказывает устаревание CLI.
  Срок действия токена не обновляет.
- `trace_start.sh` — исходная неудачная попытка трассировки. Требует strace;
  в проверенной среде ptrace запрещён. Отсутствие `--foreground` и перенаправление
  вывода также делают этот скрипт неподходящим для финального теста CLI.
  Сохранён без исправлений для воспроизводимости истории диагностики.
  Запускать для проверки работоспособности нужно команду из основного README.

Сырые логи не сохранены в проекте: они могут содержать персональные данные.
